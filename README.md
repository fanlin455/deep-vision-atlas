# 深地智境

石油工程智能算法可视化实验平台，覆盖13个作业环节和104个交互案例。

网站采用离线可运行的静态前端，包含作业地图、13类精细三维工区、算法与场景关联图、案例图解和Three.js数据实验区。支持CSV与JSON数据加载、坐标映射、参数实验和结果导出。本地加载的数据用于三维及关联图表探索，算法实验仍使用案例内置教学数据。

每个案例独立压缩，下载入口为[cases.html](cases.html)。每个ZIP根目录只有一个case.json，解压后可直接打开demo/index.html。

所有场景布置、实验数据和环境图片均用于教学，不代表真实施工布置或现场效果。环境远景使用生成图片，前景为可交互Three.js几何。Three.js与JSZip采用对应许可，见assets/core中的许可及案例包内许可。

## GitHub Pages

发布源为main分支根目录，使用.nojekyll直接发布静态页面。部署后通过GitHub Pages网址访问，路由使用URL hash，无需服务端重写。
